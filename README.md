## 👋 Qui sommes-nous ?

NyoKiv Support conçoit et développe des **logiciels de bureau (.exe)** pensés pour simplifier le quotidien des petites et moyennes entreprises : moins de tâches répétitives, plus de temps pour le cœur de métier.

Chaque outil est simple à prendre en main, fonctionne en temps réel et reste à jour automatiquement.

## 🧰 Nos logiciels

| Logiciel | Description | Statut |
|---|---|---|
| **NyoKiv Location** | Gestion de location de matériel saisonnière : contrats, suivi des stocks, photos d'état des lieux, facturation | 🚧 En développement |
| *Prochainement* | D'autres outils sont en préparation | 💡 À venir |

## ✨ Nos principes

- **Simplicité** : une interface claire, sans formation nécessaire.
- **Temps réel** : les données sont synchronisées instantanément entre tous les utilisateurs.
- **Sécurité** : accès par compte, double authentification, données hébergées dans le cloud et protégées.
- **Conformité RGPD** : durées de conservation maîtrisées, données personnelles minimisées.
- **Mises à jour automatiques** : vous disposez toujours de la dernière version.
